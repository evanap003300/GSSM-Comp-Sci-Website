GSSM Computer Science Projects

Chat Bot

This project involves building a chatbot using Python and various libraries for natural language processing, along with machine learning techniques for smarter responses. We’ll be designing the chatbot to handle user queries, providing responses that mimic human-like conversations. The project is still in the early phases, and we’re focused on exploring how to train the bot and how to refine its language capabilities. Our goal is to create an intuitive and interactive chatbot while developing skills in AI, machine learning, and Python programming.

GSSM Wiki

The GSSM Wiki project is a collaborative effort to create an online resource showcasing various aspects of the school, including its culture, activities, and notable events. While it highlights the school’s values and spirit, it also incorporates some humorous inside jokes and fun details that capture the unique experience of students. Although not directly affiliated with the school itself, the wiki serves as a community-driven platform that reflects the creativity and shared experiences of its members. The project is near completion and aims to offer an engaging, informative, and lighthearted view of life at GSSM.

Image classifier

This project involves building a fruit image classification model using TensorFlow and Python to explore the fundamentals of machine learning and computer vision. The pipeline preprocesses datasets by validating image formats and resizing them, ensuring they are suitable for model training. The model is trained to identify fruits like apples, bananas, and kiwis by analyzing image features. Key achievements include creating a functional data pipeline, handling errors like invalid file types, and visualizing processed image batches. This project demonstrates foundational concepts in AI, from data preparation to model training, and serves as a hands-on approach to understanding image recognition and machine learning workflows. Future goals include implementing the training and testing of the AI model!

GOVIEos

This project involves developing a simple bootloader and operating system using x86 assembly language to explore low-level computing concepts. The bootloader interacts directly with hardware components like the CPU and BIOS, utilizing registers such as AX, BX, and DX, along with interrupt service routines. Key features thus far include loading code from the first sector of a storage device and executing basic operations like displaying characters. The project demonstrates foundational principles of operating system design and the interaction between software and hardware. It serves as a hands-on approach to understanding system architecture and low-level programming. We aim to build a simple working operating system that includes more complex features such as a file system!

Roblox Game

This project involves building a Roblox game using Roblox Studio, where we will use scripting and modeling to create a fully functional and engaging experience. The game will be developed using Lua, the primary programming language for Roblox, to implement game mechanics, interactions, and other dynamic features. While the project is still in its early stages, we are currently brainstorming ideas for the game’s theme and gameplay. Our goal is to develop a creative and enjoyable game that will engage players while learning more about game development and Roblox’s platform.

2d Game

This project involves creating a 2D game using the Love2D framework, which allows for easy game development with Lua. We will focus on designing the game mechanics, characters, and environments while leveraging the framework’s tools to manage graphics, sounds, and physics. The project is still in its early stages, and we are exploring different gameplay concepts and artistic styles. Our goal is to create an engaging 2D game that blends fun mechanics with smooth controls, while gaining hands-on experience in game development and programming.
