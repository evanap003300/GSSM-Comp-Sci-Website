# Computer Science Department Website

This is a custom website I designed and developed for the Computer Science Department at my school. The site serves as an accessible and clean resource hub for students, prospective families, and faculty — highlighting course offerings, clubs, and research opportunities.

## 💻 Technologies Used
- **HTML5** — For semantic and structured web content.
- **CSS3** — For responsive design and visual styling.

## 🎯 Project Purpose
The goal of this project was to create a simple, easy-to-navigate website that showcases the department's academic focus, extracurricular activities, and student achievements. The website was designed with user experience in mind, offering clear navigation and consistent visual hierarchy.

## 🛠 Features
- Clean and modern landing page.
- Sections for club listings, course descriptions, and contact information.
- Fully responsive layout for both desktop and mobile devices.
- Easy-to-maintain structure for future content updates.

## 📌 What I Learned
- How to structure real-world webpages using semantic HTML.
- CSS best practices for layout, spacing, and responsive design.
- The importance of designing for both usability and maintainability.
